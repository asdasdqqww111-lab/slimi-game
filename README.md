# slimi-game

## SLIMI — الرفيق الافتراضي الذكي الناطق ثلاثي الأبعاد للأندرويد (Godot 4.7.2)

مشروع **SLIMI** مبني باستخدام **Godot 4.7.2-stable** ولغة **GDScript** بمعمارية معيارية نظيفة قابلة للتوسع، وموجّه لهواتف **Android 8.0+ (API 26+)** عبر **Compatibility Renderer (`gl_compatibility`)** لأداء مستقر وسريع.

---

### الهوية البصرية المرجعية المحفوظة لـ SLIMI

- جسم هلامي وردي شفاف وناعم يحافظ على الحجم الفيزيائي أثناء التشوه والارتداد (`slime_jelly.gdshader`).
- عيون لامعة كبيرة مرسومة بالنجوم المجرّية (`slime_galaxy_eye.gdshader`) مع حواجب ثلاثية الأبعاد (`LeftBrow` / `RightBrow`) وجفون متحركة.
- خدود وردية متوهجة قابلة للانتفاخ التعبيري وفم ثلاثي الأبعاد ناطق بلسان وردي.
- **قرنا استشعار شفافان** (`StarAntenna` بنجمة لامعة + `RightFeeler` الهلامي الشفاف).
- **قبعة صوفية صفراء محبوكة** بكرة صوفية بيضاء منفوشة (`PomPom`) ووردة خيوط ملونة (`YarnFlower`) ودبوس قلب لامع.

---

### المعمارية المعيارية لمنظومة الرفيق الذكي (`scripts/companion/`)

تتواصل الأنظمة العشرة عبر إشارات Godot (`Signals`) ومنسق أحداث موحد دون تشابك معقد:

1. **`SlimiVoiceManager`**: نظام الصوت متعدد الطبقات (22 صوتاً تعبيرياً رقيقاً ودافئاً + توليد مقطعي نغمي للكلام + دعم النطق النظامي الاختياري `DisplayServer.tts_speak` + مزامنة حية لحركة الفم والحواجب `Lip-Sync`).
2. **`SlimiEmotionManager`**: محرك المشاعر الكامل (**20 شعوراً حقيقياً**: السعادة، الحزن، الحب الودود، الفضول، الخجل، الخوف، المفاجأة، الغضب اللطيف، الهدوء، الحماس، الملل، النعاس، التعب، الوحدة، الثقة، الامتنان، المرح، الغيرة التمثيلية الخفيفة، الإحباط، والاطمئنان) يؤثر كل منها في الوجه والوقفة ونبرة الصوت والسلوك.
3. **`SlimiAnimationController`**: **31 حركة يومية وكوميدية وظريفة ونادرة** (12 يومية + 19 كوميدية تشمل الاختباء خلف القبعة، التعثر اللطيف، نفخ الخدود، مد اللسان، اللعب بقرون الاستشعار، هز القبعة الصفراء، إرسال قبلة، والاحتفال بالفوز) مع نظام أولوية يمنع تعارض حركتين معاً.
4. **`SlimiDialogueManager`**: نظام حوار وترفيه ذكي ثنائي اللغة (**العربية الفصحى المبسطة + الإنجليزية**) يفهم التحيات والشكر والحزن والفرح والأسئلة، ويقدم نكتاً غير متكررة، ألغازاً تفاعلية متعددة الخطوات، قصصاً قصيرة، ومشاهد تمثيلية، مع ترحيب متغير حسب الوقت وخالٍ تماماً من أي عتاب أو ضغط عاطفي.
5. **`SlimiPersonalityManager`**: سمات شخصية قابلة للتخصيص (الفكاهة، الفضول، الدفء، الهدوء، النشاط) وتطور تدريجي للثقة حسب معاملة المستخدم (المسح اللطيف، الإهمال، الضغط الهلامي، التخويف والاطمئنان التدريجي).
6. **`SlimiBehaviorAI`**: ذكاء سلوكي مستقل (**Utility AI**) يقيم الأفعال حسب المشاعر والطاقة والفضول والملل ونقاط الغرفة مع احترام الهدوء التام عند عدم التفاعل.
7. **`SlimiMemoryManager`**: ذاكرة محلية محدودة الحجم وآمنة (اللقب الاختياري، التفاعل والألعاب المفضلة، المحطات، ومقتطفات دردشة بموافقة المستخدم مع فلتر يمنع حفظ أي مفاتيح سرية + زر مسح الذاكرة بالكامل).
8. **`SlimiMiniGames`**: **9 ألعاب مصغرة وتحديات قابلة للعب فعلياً** (الغميضة، تقليد الحركات، لعبة الذاكرة، تخمين الرقم، القفز على الإيقاع، مطاردة الإصبع، اختيار الوجه التعبيري، أسئلة وأجوبة، والتحدي اليومي) مع تفاعل SLIMI عند الفوز والخسارة.
9. **`SlimiSettingsManager`**: إدارة الوضع الافتراضي `Offline` والوضع الاختياري `AI Online` واختيار المزود وتشفير مفتاح API محلياً خارج ملفات اللعبة المكشوفة.
10. **`SlimiInteractionManager`**: ناقل الأحداث الموحد وإدارة الاستماع الصوتي عبر الميكروفون بإذن صريح فقط مع مؤشر حي واضح (`🔴 الميكروفون نشط الآن...`).

### التمييز الدقيق بين الأنظمة المنفذة محلياً والخدمات الخارجية الاختيارية

| الميزة / النظام | التنفيذ المحلي 100% داخل المحرك (الافتراضي بدون إنترنت) | التكامل الخارجي / النظامي الاختياري (يتطلب تفعيل المستخدم أو دعم النظام) |
|---|---|---|
| **الأصوات التعبيرية ومزامنة الفم (Lip-Sync)** | مُنفذ محلياً بالكامل عبر `ProceduralSoundBank` (22 صوتاً + توليد مقطعي نغمي ومصفوفة Visemes حية). | عند توفر محرك `TextToSpeech` على هاتف Android ينطق الكلمات بصوت النظام مع بقاء الـ Lip-Sync والتوليد المحلي بديلاً فورياً. |
| **الدردشة الذكية، النكت، الألغاز، القصص، والتمثيليات** | يعمل محلياً 100% في وضع `Offline` الافتراضي بالعربية والإنجليزية دون أي اشتراك مدفوع أو إنترنت. | وضع `AI Online` اختياري تماماً عبر `HTTPRequest` غير متزامن فقط إذا فعّله المستخدم ووافق صراحةً وأدخل مفتاح API خاصاً به. |
| **التفاعل الصوتي (الميكروفون)** | التقاط تردد وطاقة الصوت الحي محلياً عبر `AudioStreamMicrophone` + `AudioEffectCapture` مع استجابة صوتية محلية ومؤشر حي، ولا يُفتح الميكروفون إلا بطلب المستخدم الصريح (`RECORD_AUDIO`). | التحويل السحابي للكلام إلى نص (Cloud STT) غير مفروض ولا تُرسل أي تسجيلات صوتية لجهات خارجية دون موافقة. |
| **المشاعر الـ 20، الحركات الـ 31، الألعاب الـ 9، والذاكرة** | منفذة ومختبرة محلياً 100% داخل Godot 4.7.2 مع حفظ ذري محلي في `user://`. | لا تعتمد على أي خدمة خارجية. |

### مراحل التنفيذ الأربع

- **المرحلة 1**: الصوت متعدد الطبقات + تحريك الفم والحواجب + قرنا الاستشعار الشفافان + محرك الـ 20 شعوراً + متحكم الـ 31 حركة يومية وكوميدية.
- **المرحلة 2**: الحوار المحلي الذكي ثنائي اللغة + النكت والألغاز والقصص والمشاهد + تطور الشخصية + الذكاء السلوكي المستقل (`Utility AI`).
- **المرحلة 3**: الذاكرة الآمنة المحدودة القابلة للمسح + الألعاب المصغرة الـ 9 + إعدادات الخصوصية ومزود الذكاء الاختياري + واجهة نظيفة غير مزدحمة.
- **المرحلة 4**: تحسين الأداء (`< 0.1 ms` منطق إطار المعالج، `0` عقد يتيمة) + اختبار عملي شامل (`126/126 PASS`) + بناء وتوقيع حزمة `APK` للأندرويد عبر GitHub Actions.

### التشغيل والاختبار الآلي الشامل عبر Godot Headless

```bash
# 1. استيراد موارد المشروع
godot --headless --import --path .

# 2. تشغيل حزمة الاختبارات الشاملة (126 اختباراً عملياً تغطي جميع الأنظمة)
godot --headless --path . res://tests/TestRunner.tscn
```

### التصدير إلى Android (`APK`)

```bash
godot --headless --path . --export-debug "Android" build/android/slimi-debug.apk
```
