# slimi-game

## SLIMI — لعبة سلايم ثلاثية الأبعاد للأندرويد (Godot 4.7)

مشروع لعبة **SLIMI** مبني باستخدام **Godot 4.7.2-stable** ولغة **GDScript** مع معمارية هندسية نظيفة وقابلة للتوسع، مصمم خصيصاً لهواتف **Android 8.0+ (API 26+)** بالاعتماد على **Compatibility Renderer (`gl_compatibility`)** لضمان سلاسة الأداء والعمل الكامل دون إنترنت.

---

### أبرز المزايا والأنظمة المنفذة

1. **شخصية SLIMI ثلاثية الأبعاد (`SlimeController` + `SlimeDeformer` + `SlimeFaceRig`)**
   - جسم هلامي وردي باستيل لامع بخامة مخصصة (`slime_jelly.gdshader`) تدعم انضغاط القاعدة، اللمعان اللؤلؤي (Fresnel Rim)، التوهج الداخلي الناعم، وموجات اللمس الموضعية.
   - تشوه مرن فيزيائي بنوابض مخمدة مع حفظ الحجم ثلاثي الأبعاد (Volume-Preserving Squash & Stretch) واهتزاز متعدد المحاور (3D Jiggle).
   - عينان كبيرتان ثلاثيتا الأبعاد مع تتبع نظر، جفون متحركة، رمش طبيعي، خدود موردة، وفم ثلاثي الأبعاد يتشكل إجرائياً بحسب التعبير.

2. **نظام التفاعل واللمس (`TouchInteractionSystem`)**
   - تتبع أشعة ثلاثي الأبعاد (`PhysicsDirectSpaceState3D`) يدعم شاشات اللمس في Android والفأرة للتجربة المكتبية.
   - يميز بين: النقر السريع (Poke/Tickle)، المسح الحنون المستمر (Petting)، السحب المطاطي والإفلات (Elastic Pull & Release)، النقر على أرضية الغرفة للقفز إليها، وتدوير زاوية الكاميرا بلطف.

3. **الشخصية والمزاج والذاكرة المحلية (`PersonalityMoodSystem` + `SlimeMemory`)**
   - منظومة احتياجات ومشاعر ديناميكية: السعادة، الطاقة، الشبع، الألفة، والفضول.
   - ذاكرة محلية تتذكر عدد الزيارات، اللمسات، المسحات، وجبات الحلوى، مستوى العلاقة، والتفاعل المفضل عبر الجلسات، مع احتساب لطيف لفترة الغياب.

4. **الذكاء الاصطناعي للسلوك المستقل (`AutonomousBehaviorAI`)**
   - آلة حالات موزونة بالمنفعة (Utility-Weighted FSM): المراقبة الهادئة، التجول بالقفز، الاستكشاف الفضولي لأثاث الغرفة، القفز المرح، طلب الانتباه، والغفوة التلقائية لاستعادة الطاقة.

5. **الصوتيات الإجرائية الأصلية (`ProceduralSoundBank` + `AudioManager`)**
   - توليد أصوات سلايمي المرحة بصيغة PCM 16-bit مباشرة عبر الكود دون الحاجة لأي ملفات صوتية ثنائية أو أصول غير مرخصة.

6. **الغرفة الافتراضية ثلاثية الأبعاد (`CozyRoom.tscn` + `RoomEnvironment`)**
   - غرفة باستيل دافئة بإضاءة ناعمة متكيفة مع مستويات الجودة الرسومية، وسادة مريحة، وعاء طعام تفاعلي، كرة لعب، ونبتة زاوية.

7. **واجهة عربية RTL قابلة للتوسع (`GameHUD.tscn` + `LocalizationManager`)**
   - واجهة هاتف نظيفة بوضع ملء الشاشة ودعم الحواف الآمنة (Safe Area / Cutouts)، مع دعم كامل للعربية (`RTL`) وإمكانية التوسع والتبديل الفوري للغات أخرى (`LTR`).

8. **الأداء ومستويات الجودة والحفظ الذري (`QualityManager` + `SaveManager` + `AndroidPlatformManager`)**
   - ثلاثة مستويات جودة رسومية فورية: **منخفضة**، **متوسطة**، **عالية**، مع خيار توفير البطارية (30 إطار/ث).
   - حفظ واستعادة ذري محلي (`user://slimi_save.json` + نسخة احتياطية تلقائية عند إيقاف التطبيق مؤقتاً على Android).

### هيكل المشروع

```text
├── assets/                 # أيقونة المتجهات (SVG) ومورد الخط العربي النظامي
├── audio/                  # المولّد الصوتي الإجرائي وإعدادات الأصوات
├── materials/              # خامات المشهد والشيدر الهلامي (slime_jelly.gdshader)
├── resources/              # موارد الشخصية، إضاءة الغرفة، وثيم الواجهة الباستيل
├── scenes/                 # المشاهد المنفصلة (Main, Slimi, CozyRoom, GameHUD)
├── scripts/                # السكربتات المقسمة حسب الأنظمة (core, slime, ai, interaction, environment, ui)
├── tests/                  # حزمة الاختبارات الآلية الشاملة عبر Godot Headless
├── project.godot           # إعدادات مشروع Godot 4.7
└── export_presets.cfg      # إعدادات تصدير Android (API 26+ / Android 8.0+)
```

### التشغيل والفحص عبر Godot Headless

```bash
# 1. استيراد موارد المشروع وفحص سلامة المشاهد والسكربتات
godot --headless --import --path .

# 2. تشغيل حزمة الاختبارات الآلية الشاملة
godot --headless --path . res://tests/TestRunner.tscn
```

### التصدير إلى Android (APK / AAB)

تم تجهيز `export_presets.cfg` لاستهداف **Android 8.0+ (`min_sdk = "26"`)** لمعماريات `arm64-v8a` و`armeabi-v7a` باستخدام `gl_compatibility` دون أي مفاتيح سرية مخزنة في المستودع:

1. ثبّت **Godot 4.7.2 Export Templates** و**Android SDK + JDK 17**.
2. عيّن مسار `Android SDK` ومفتاح التوقيع المحلي (`debug.keystore`) في إعدادات محرر Godot (`Editor Settings -> Export -> Android`).
3. صدّر الحزمة عبر المحرر أو سطر الأوامر:
   ```bash
   godot --headless --path . --export-debug "Android" build/android/slimi-debug.apk
   ```
4. يتضمن المستودع أيضاً مسار بناء تلقائي عبر GitHub Actions في `.github/workflows/godot-ci.yml`.
